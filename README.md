# 🕵️‍♂️ Imposter! (המתחזה!)

ברוכים הבאים למשחק **Imposter!** – משחק חברה מותח וממכר בו כולם יודעים מה המילה הסודית... חוץ מאחד!

## 🎮 על המשחק
במשחק זה, תיכנסו לנעליים של חוקרים או של מתחזים. תעבירו את הטלפון מאחד לשני כדי לגלות מה המילה הסודית של הסיבוב, כאשר אחד מכם (או יותר) יגלה שהוא "המתחזה" ואין לו מושג על מה כולם מדברים! 
המטרה של השחקנים הרגילים היא למצוא את המתחזה, והמטרה של המתחזה היא להשתלב בשיחה בלי להיתפס.

## ✨ תכונות מרכזיות
* **ממשק מודרני ואלגנטי**: עיצוב "Glassmorphism" חללק, נקי, כהה ומושך את העין.
* **תמיכה מלאה בעברית**: הקוד והעיצוב מותאמים לחלוטין לקריאה מימין לשמאל (RTL).
* **נושאים מגוונים**: מגוון קטגוריות למשחק (חיות, ארצות, מקצועות, ספורט ועוד) באמצעות מערכת מודולרית ודינמית המבוססת על קובצי JSON.
* **התאמה למובייל (PWA)**: ניתן להתקין ולשחק ישירות מכל מכשיר נייד בצורה חלקה ומהירה כאפליקציה לכל דבר.
* **זרימת משחק מהירה**: בלי מסכים או תפריטים מיותרים – ישר ולעניין.

## 🚀 איך משחקים?
1. בוחרים את מספר השחקנים, כמות המתחזים ואת נושאי המשחק הרצויים.
2. לוחצים על "התחל משחק".
3. כל שחקן בתורו מקבל את הטלפון ולוחץ על הכרטיסייה כדי לגלות אם הוא קיבל את המילה הסודית או שהוא מוגדר כמתחזה.
4. לאחר שכולם ראו את כרטיסייתם, השחקנים רומזים רמזים קלים אחד לשני על המילה. בזמן הזה, המתחזה מנסה להשתלב מבלי להיחשף! הרמזים צריכים להיות מספיק מובנים לאלו שיודעים את המילה, אך מספיק עמומים כדי לא לחשוף אותה בפני המתחזה.

## 🛠️ טכנולוגיות
- **HTML5** – תגיות סמנטיות נכונות למבנה.
- **CSS3** – לעיצוב, אנימציות, וריספונסיביות מלאה.
- **Vanilla JavaScript** – לוגיקת משחק רזה ויעילה, ניהול מצבי המשחק וטעינת הקטגוריות.
- **Service Workers** – לתמיכה אופליין ואפשרות התקנה (PWA).

## 📦 הוראות הרצה (למפתחים)
מעוניינים להריץ את המשחק בסביבת הפיתוח המקומית שלכם?

1. שפלו את המאגר (Clone) למחשב שלכם:
```bash
git clone https://github.com/savihay/imposter.git
```

2. היכנסו לתיקיית הפרויקט:
```bash
cd imposter
```

3. הפעילו שרת ווב מקומי (Local Server). אפשר להשתמש ב-Node.js עם חבילת `serve` למשל:
```bash
npx serve .
```

4. פתחו את הדפדפן המועדף עליכם הנווטו לכתובת המקומית (לרוב תהיה `http://localhost:3000`).

## 📝 הוספת נושאים חדשים או מילים
המשחק בנוי כך שיהיה פשוט מאוד להוסיף מילים חדשות להרחבת משחק הבסיס!
גישו לתיקיית `topics/` בפרויקט, עדכנו או צרו קובץ `.json` חדש הכולל רשימת מילים חדשה (מערך פשוט של מחרוזות). במידה ויצרתם נושא חדש לחלוטין, הקפידו להוסיף אותו גם לקובץ המאגד `index.json`.
